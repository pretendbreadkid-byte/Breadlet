# Blooket Trade Visualizer

A lightweight Chrome/Edge browser extension that helps you plan a visual Blooket trade. You can mark blooks you are giving away in grey and blooks you are receiving in green, even if you do not actually own the ones you are requesting.

## Install
1. Open Chrome or Edge.
2. Go to Extensions.
3. Enable Developer mode.
4. Click Load unpacked.
5. Select this folder.

## How to use
1. Open a Blooket page.
2. A floating panel will appear in the corner.
3. Click Give or Get, then click a visible blook card to add it to the preview.
4. Use Clear to reset the preview.

## Notes
- This is a visual planning tool only.
- It does not change your inventory or perform a real trade.
